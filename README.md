# Make the Judge Laugh in One Line

One funny line (112 characters) about a GPS that declares arrival far too early, entered in the [make.fun bounty](https://make.fun/bounty/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21).

> My GPS said 'you have arrived' while I was still on the highway — the most confidence anyone has ever had in me.

`main.py` writes the line to `/output/entry.txt` and prints it to stdout. Deterministic: byte-identical output on every run.

## Run

```sh
python3 main.py
```
